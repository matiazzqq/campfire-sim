## 🔥 О игре

Ночь. Лес. Костёр. Твоя задача — не дать огню погаснуть. Собирай дрова, подкидывай их в костёр, жарь зефир и лови светлячков. Спокойная, медитативная игра без врагов и таймеров.

## ✨ Особенности
- 🔥 **Реалистичный огонь**: частицы пламени, дым, свет на земле.
- 🪵 **Сбор ресурсов**: брёвна появляются по краям экрана.
- 🍡 **Жарка зефира**: держи огонь выше 50%, чтобы жарить.
- ✨ **Светлячки**: летают по экрану, дают бонусы.
- 🌙 **Атмосфера**: мерцающие звёзды, луна, силуэты деревьев.
- ⭐ **4 улучшения**: авто-дрова, затухание, сбор, зефир.
- 🔊 **Процедурный звук**: треск костра через шумовые буферы.

## 🕹 Управление
Всё мышкой или пальцем:
- Клик по бревну → собрать дрова
- Клик по костру → подкинуть дрова
- Клик по зефиру → жарить / забрать
- Клик по светлячку → бонус
